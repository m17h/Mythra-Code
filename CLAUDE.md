# Mythra Code repository rules

Read and follow `AGENTS.md` before working in this repository. It owns the
development and merge rules for all agents. Use `docs/operations/merging.md`
for the merge procedure and `docs/operations/releasing.md` for explicitly
authorized releases (follow its "Instructions for agents" steps exactly).
Automated tests and checks are disabled locally and on GitHub until Morgan
explicitly reintroduces them. Do not restore test or audit gates from old
reports, private notes or earlier instructions.
