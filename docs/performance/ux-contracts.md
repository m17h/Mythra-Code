# Performance and visible behavior

Automated browser contracts and performance tests are disabled until Morgan
explicitly reintroduces them. No browser or native test gate is required.

Performance changes should preserve access to loaded history, copy/search,
keyboard controls, progress and command details, final replies, animations and
reduced-motion behavior. A smaller DOM or faster synthetic measurement does not
establish an improvement if people lose content or controls.

The earlier UX-contract tests and their results are historical records and may
refer to removed files. See [performance notes](../PERFORMANCE.md).
